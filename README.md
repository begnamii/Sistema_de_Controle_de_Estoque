### Sistema de Controle de Estoque Simplificado (SCES).

O programa funciona como um sistema de estoque de produtos.

Cada produto precisa de um ID, um nome, uma quantidade e uma localização.

O estoque já possui 3 produtos iniciais (você pode utiliza-los ou apaga-los e criar os seus).

Ele possui um menu interativo para navegar pelo estoque.

O menu possui 7 opções de ações:
1. Adicionar produto (o ID é atualizado automaticamente, os outros elementos o usuário coloca);
2. Listar todos os produtos (mostra todas as informações de todos os produtos);
3. Buscar produto por ID (O usuário digita o ID do que produto que ele quer vizualizar e é mostrado as informações do produto);
4. Atualizar estoque (pede ao usuário o ID do produto que ele quer atualizar a quantidade e a nova quantidade);
5. Estoque mínimo (alerta o usuário sobre os produtos com menos de 5 unidades disponíveis no estoque);
6. Excluir produto (pede ao usuário o ID do produto que quer excluir, mostra o produto e pergunta se é realmente esse produto que dejesa excluir);
7. Sair (fecha o menu e o funcionameto do sistema).

Caso o caractere não corresponda a nenhuma opção, o sistema avisará e voltará a página inicial do menu.
